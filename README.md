# Kairo — static marketing site

A complete static site. No build step needed to view it: open `index.html`,
or serve the folder (`python3 -m http.server 8000`).

## Structure

```
index.html                  home
pricing.html                pricing + FAQ
compare.html                honest category comparison
about.html                  about + contact
demo.html                   trial / walkthrough (form is inert)
product/                    overview + 5 product pages
customers/                  index + 2 written case studies
blog/                       index + 12 long-form posts
tools/                      ABM budget calculator (works, vanilla JS)
legal/                      terms + privacy (placeholders)
assets/site.css             the entire design system
assets/*.svg                logo mark, reversed mark, favicon
sitemap.xml, robots.txt
```

## Before you put this anywhere public

- Every company name, customer quote, logo and benchmark figure is **placeholder**.
  Search for `PLACEHOLDER` in `pages_main.py` / `pages_more.py`.
- `legal/terms.html` and `legal/privacy.html` are structural placeholders, not legal documents.
- `demo.html` has an inert form — wire it to your own endpoint.
- Register `kairoabm.com` (confirm availability at a registrar first).

## Regenerating

The HTML is generated by Python, so edits are best made at source:

```
python3 build.py
```

- `lib.py` — layout, header, footer, shared components
- `pages_main.py` — home and product pages
- `pages_more.py` — pricing, compare, customers, calculator, about, demo, legal
- `posts_a.py` / `posts_b.py` — the 12 blog posts
- `blog.py` — blog index and post rendering
