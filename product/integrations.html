Webhooks

REST API

MCP server

API

Designed to be read by something that is not a person

Every object in the interface has an endpoint, and the field names are the same in both places. No undocumented internal shapes, no CSV-shaped API.

  • Bearer-token auth, scoped keys, per-key audit log
  • Cursor pagination, updated_since on every collection
  • Sandbox workspace with generated data for building against
  • OpenAPI schema, so a client generates itself

Data handling

The boring commitments, stated plainly

Your data is not training data

Target lists, CRM records and campaign data are never used to train models and are never pooled across customers. Benchmarks are opt-in and computed on anonymised minimum cohorts.

Regional storage

EU and US data residency, chosen at workspace creation. Sub-processors are listed publicly and changes are announced 30 days ahead.

Deletion means deletion

Workspace deletion removes derived records too, not just the rows you uploaded. Confirmation is issued within 30 days.
